# Hospital Management System

## Overview

This project is a **Spring Boot backend application** that implements a simple Hospital Management System.
It focuses on building secure REST APIs using **JWT authentication** and performing **CRUD operations** on patient data.

---

## Features

* User Registration and Login
* JWT-based Authentication
* Secure API Access
* Patient Management (Create, Read, Update, Delete)

---

## 🛠️ Technologies

* Java
* Spring Boot
* Spring Security
* JWT
* Spring Data JPA
* MySQL
* Maven
